# Shreya Secret Gift

A responsive, static surprise website for Shreya.

## Files
- `index.html` — page structure
- `style.css` — futuristic purple/pink styling and animations
- `script.js` — password unlock, surprise reveal, and generated ambient tones

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Password
`shreya`

## Publish free with GitHub Pages
1. Upload the *contents* of this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then Save.
5. Wait for the deployment to finish.

Note: the password is a client-side screen lock, not secure authentication. Anyone who inspects the source code can find it. Do not put private information on a public site.
